# Grupo Volkswagen — Projeto HTML

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica para colocar em prática os conhecimentos de HTML estudados em aula.

O site apresenta informações sobre o Grupo Volkswagen, sua história, evolução, principais marcas, automóveis, motores, tecnologias e conteúdos relacionados ao universo automotivo.

O projeto foi desenvolvido utilizando somente HTML, sem o uso de CSS ou JavaScript.

---

## Objetivo

O objetivo principal do projeto foi desenvolver um site com várias páginas e aplicar diferentes recursos do HTML, desde elementos básicos até recursos mais avançados.

Durante o desenvolvimento foram utilizados elementos de estrutura, navegação, imagens, áudios, vídeos, tabelas, formulários, elementos semânticos e elementos de marcação de texto.

---

# Estrutura do projeto

O projeto foi organizado da seguinte forma:

- `html/` — contém todas as páginas HTML do site.
- `img/` — contém as imagens utilizadas no projeto.
- `audio/` — contém os arquivos de áudio.
- `video/` — contém os vídeos utilizados no site.
- `README.md` — contém a explicação e informações sobre o projeto.

# Recursos de HTML utilizados no projeto

## Estrutura semântica

Foram utilizados elementos semânticos para organizar melhor o conteúdo das páginas:

- `<header>` — cabeçalho.
- `<nav>` — menu de navegação.
- `<main>` — conteúdo principal.
- `<section>` — divisão do conteúdo em seções.
- `<article>` — organização de conteúdos independentes.
- `<aside>` — informações complementares.
- `<footer>` — rodapé.

---

## Navegação

Todas as páginas possuem um menu com links utilizando a tag `<a>`.

Os links permitem navegar entre as diferentes páginas do projeto.

---

## Imagens

As imagens utilizadas no projeto estão armazenadas localmente na pasta `img/`.

Também foram utilizados:

- `<figure>` — organização da imagem.
- `<figcaption>` — legenda da imagem.
- `<img>` — inserção das imagens.
